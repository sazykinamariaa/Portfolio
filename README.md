## Проект 1 — Анализ данных велопроката

**Задача:** выявить паттерны спроса для оптимизации управления парком велосипедов.  
**Данные:** Seoul Bike Sharing Dataset, 8 760 почасовых наблюдений за 2017–2018 гг.  
**Инструменты:** Python, pandas, matplotlib

**Ключевые находки:**
- Велопрокат используется как транспорт, а не для досуга — два пика спроса совпадают с началом и концом рабочего дня
- Летом спрос в 4.5 раза выше чем зимой, корреляция с температурой 0.45
- Пятница — максимальный день, воскресенье — минимальный (разница 16%)

**Файлы:** `Велопрокат_проект.ipynb`, `BikeData.csv`

## Проект 2 — Описание бизнес-процесса (BPMN)

**Задача:** описать и оптимизировать процесс проведения очного этапа олимпиады «Высшая проба» (НИУ ВШЭ).  
**Роль:** участник процесса (волонтёр на олимпиаде 2025 года).  
**Инструменты:** BPMN 2.0, bpmn.io

**Что сделано:**
- Описан процесс: 3 роли (участник, волонтёр, организатор), 2 развилки, эскалация при нарушениях, 2 финала
- Выявлено узкое место: волонтёры не ориентируются в чужом корпусе
- Предложено улучшение: брифинг с обходом ключевых точек за час до начала

**Файлы:** `Описание_процесса_заключительный_этап.pdf`, `diagram.png`
