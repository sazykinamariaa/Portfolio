## Проект 1 — Анализ данных велопроката

**Задача:** выявить паттерны спроса для оптимизации управления парком велосипедов.  
**Данные:** Seoul Bike Sharing Dataset, 8 760 почасовых наблюдений за 2017–2018 гг.  
**Инструменты:** Python, pandas, matplotlib

**Что сделано:** разведочный анализ данных (EDA), проверка 3 гипотез о природе спроса, визуализация паттернов, подготовка executive summary с рекомендациями по оптимизации парка

**Ключевые находки:**
- Велопрокат используется как транспорт, а не для досуга — два пика спроса совпадают с началом и концом рабочего дня
- Летом спрос в 4.5 раза выше чем зимой, корреляция с температурой 0.45
- Пятница — максимальный день, воскресенье — минимальный (разница 16%)

**Файлы:** `Велопрокат_проект.ipynb`, `BikeData.csv`

## Проект 4 — Анализ HR-данных и распределение бюджета на повышения

**Задача:** помочь руководителю принять решение по пересмотру окладов в рамках бюджета 960 000 руб.  
**Данные:** 122 сотрудника, 6 месяцев, 3 файла (hr_dataset_raw, salary_bands, budget).  
**Инструменты:** Python (pandas), Excel (СУММЕСЛИМН, Power Query), Google Slides

**Что сделано:**
- Очистила данные в Python: исправила 18 форматов записи, опечатки и пропуски
- Сравнила оклады с рыночными вилками с учётом частичной ставки
- Выявила 9 сотрудников ниже минимума — приоритет на повышение
- Распределила бюджет в два приоритета: 56 сотрудников получили повышение, остаток 194 000 руб. зарезервирован

**Ключевые находки:**
- 64% сотрудников находятся ниже середины рыночной вилки — системная проблема, а не единичные случаи
- Разрыв между лидером и аутсайдером по выполнению плана составляет 11.4х
- Бюджет 960 000 руб. покрывает оба приоритета повышений, остаток 194 000 руб. зарезервирован

**Файлы:** `HR_salary_analysis.ipynb`, `HR_analysis_budget.xlsx`

**Презентация:** [Google Slides](https://docs.google.com/presentation/d/1wZzYkTXP47OsoAtD9YjJdaI7al4ULSZMosPpog14sAQ)
